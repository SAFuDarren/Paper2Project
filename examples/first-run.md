# First run

Ask a compatible host agent: "Use Paper2Project for this selected research folder. Reuse my known language and reading preferences, ask only missing design choices, and keep existing files intact."

The agent reads context that is actually available, prepares normalized signals and a small design, then uses the commands in [onboarding](../references/onboarding.md). No memory API, API key or background service is required. Public example signals/cards are fictional, not extracted from a user's memory.
